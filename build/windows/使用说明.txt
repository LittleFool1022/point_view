Point View 0.1.6 Windows x64 文件夹版

1. 在 Windows 中将 ZIP 全部解压到一个独立文件夹，只需解压一次。
2. 双击文件夹内的 Point View.exe 启动应用。
3. 后续直接运行该 exe，启动时不再静默释放整套应用到临时目录。
4. 请保留 exe 旁边的 resources、locales、DLL 等全部文件；不要只复制 exe，也不要在压缩包内直接双击 exe。
5. Python、Open3D 与重建所需的运行库已随包提供，不需要单独安装。
6. 本版保留完整功能与依赖，展开后仍占用约 932 MiB；更改的是应用启动方式。

如需桌面快捷方式，也可使用同批交付的 Point View Setup 0.1.6.exe 安装版。安装结束后从快捷方式启动，应用无需每次重新解压。

作品、草稿和设置保存在 Windows 当前用户的应用数据目录。跨电脑继续制作请保存 .pvobject 工程。

本包已进行构建与包内容检查，Windows 真机窗口显示和重建功能仍需实际测试。
