# 手持扫描 App 前端演示

独立入口：`/handheld.html`。这是手机 App 演示，不提供桌面产品布局；电脑打开显示手机预览框。原 `/` 工作台保留。

启动：

```sh
npm run dev:handheld
```

## 分享单个离线 HTML

交付文件：`release/OMNI-Scan-手机App演示.html`，约 0.83 MiB。可直接将该文件发送给同事；下载后使用浏览器打开，不要求连接同一局域网，也不需要运行开发服务器。聊天软件若只显示源码，请下载文件后选择浏览器打开。

重新打包：

```sh
npm run pack:handheld
```

脚本将 React、Three.js、界面脚本与样式打入一个 HTML，不使用 CDN。电脑端手机画幅使用内嵌页面，进入扫描自动横屏；手机端直接显示 App 页面。

已用 Chromium 在断网条件下通过 `file://` 打开最终文件，检查电脑手机画幅、模拟连接/初始化/自动横屏/保存/下载以及 JSON 文件导出，并打开 390px 手机视口。结果：浏览器 `pageErrors: []`、HTTP 请求 `httpRequests: []`。这是浏览器离线交付验证，未进行 Android 真机验收。

也可以在已运行的 Vite 开发服务器地址后加 `/handheld.html`。手机与电脑在同一网络时，可使用电脑的局域网地址和相同端口打开。

## 演示内容

- 手机 App 专用布局、素材/指南、手机/设备项目列表、项目详情。
- 浏览器程序生成的可旋转工作室模型，点云/实体切换、高度着色、视角复位和俯视。
- 模拟连接、初始化、扫描计时、暂停/恢复、结束保存；模拟断线不会结束模拟设备会话。
- 演示记录在独立 localStorage 键 `point-view-handheld-demo-v1` 中保存，不访问原工作台的项目库。
- 项目重命名、搜索、排序、确认删除；模拟设备下载到手机、手机上传云端两个阶段。
- 在示例地面点选两个位置，计算程序模型平面距离；切片滑块真实控制模型裁切范围。
- 导出带 `demo` 标记的 JSON 清单；DXF 是固定示意平面，不是由当前切片生成的成果。
- 安卓竖屏与横屏扫描布局；电脑仅展示手机画幅，进入扫描自动切换横屏预览，可手动旋转。原生对话框支持关闭与键盘焦点。

## 体验路径

1. 点击“开始新扫描”，连接演示设备。
2. 输入项目名并选择分类，开始模拟初始化。
3. 拖动旋转场景，切换点云/实体、暂停/继续；可在连接面板模拟断线和恢复。
4. 点击方形结束按钮，确认保存，进入演示项目详情。
5. 模拟下载到手机，开启“测量”或“切片”。测量只接受示例地面范围内的点击。
6. 体验上云流程，或下载演示清单/示意 DXF。

## 当前边界

这是 React UI 演示，没有接入真实 Foxglove、Tauri 原生桥、相机、网络设备、账号或云服务。点数、电量、容量、采集大小和传输进度均为演示值。三种项目缩略图是示意轴测图，三维查看共用同一程序工作室场景。
