# 物体创作台：把空间记忆带进 Blender

状态：首版已实现物体选取、表面生成、材质预览和 GLB 导出；实现范围、运行方法与真实 Blender 验收见 [实施与验收记录](object-creation-implementation.md)。下文保留原方案与实施前评估。

后续细化见 [2026-09-07 Blender 调研与综合考评](blender-research-evaluation-20260907.md)：补充全量物体提取、重建路线比较、材质往返约束及样本验收门槛。

## 产品方向

让普通用户完成「选一件 → 看清它 → 换种表达 → 留下作品」。CAD 继续负责空间图纸，物体创作负责可独立收藏、编辑和组合的三维资产。沿用石墨色工作台，让用户的物体成为画面中心；科技感来自真实的选择、形体生成和材质反馈。

现阶段将「多种素材」暂按同一物体切换材质理解；不同物体的素材库与空间布置作为后续独立能力，等待用户偏好补充。

## 新手路径

1. **选一件**：从主空间框出范围，背景淡出；允许添加、减去多余部分和撤销。提示转动查看背面，不能将屏幕框选当作准确的物体识别。先用可控选区，后续再加入点击种子后的连通区域建议。
2. **看清它**：进入物体独立预览，保持真实比例。默认「扫描原貌」，一键回到空间中的原位置。局部坐标便于旋转和导出，原始世界变换保存在对象记录中。
3. **换种表达**：提供「原色 / 石膏 / 金属 / 陶瓷」少量基础预设；拉丝等复杂效果在兼容性验证后增加。材质切换不触发重新建模、不覆盖采集颜色。滑动或按住「对照原貌」即可检查修改前后。
4. **留下作品**：命名，例如「窗边的小椅子」，生成缩略图并记录来源工程、已知采集时间和空间位置；采集时间未知时标记导入时间。主要操作为「保存物体」「导出到 Blender」，高级格式隐藏在更多选项中。

右侧 CAD 悬浮窗保持当前用途。物体创作通过工作台选区旁的入口打开，进入时关闭 CAD 并保留其模型与状态，退出返回原空间视角。避免同时摆出三套画布、三套工具。

## 扫描与创作的边界

- 扫描原貌是有坐标和颜色的点。当前数据没有三角面、法线、UV 或真实材质信息，不能只改文件扩展名就成为实体模型。
- 表面模型需要单独重建。只扫描正面的物体，背面属于未知；不默认补成完整闭合体。
- 重建不足时保留扫描原貌，并说明「这些位置的数据不足，可以保留点云，或补拍后再试」。不让用户面对算法名和一串红色分数。
- 「石膏 / 金属 / 陶瓷」是创作外观，不能冒充物体真实材质检测结果。
- 「体素 / 粒子雕塑」可以成为显式选择的艺术表达，但不能作为表面重建失败时的静默替代。

## 寓教于乐

在动作发生时解释一个概念，不设置强制教程：

- 第一次从点变成面：「点记录位置，面把附近的点连接成形体。」
- 第一次切换金属：「形状没变，光线的反射方式变了。」
- 发现缺面：「这部分尚未被记录。换个角度采集，能留下更多细节。」
- 命名并保存：「这件物体仍记得它来自空间中的哪里。」

每次只出现一句可关闭的提示。缺面说明需要重建结果或采集证据支持，不从低密度直接断言漏扫。无需积分、排行榜或强制分享。

## 工程评估

实施前源码基线（现状见上述实施记录）：

- `src/domain/types.ts:PointCloudData` 仅包含坐标、颜色、强度、可见性及属性声明。
- `src/domain/ply.ts:exportPly` 只写顶点和 RGB，没有面数据。
- `src/App.tsx:exportCloud` 当前导出整个可见点云，未提供独立物体资产或选区模型导出。
- `src/components/PointCloudCanvas.tsx` 使用 PointsMaterial，现有着色模式不是物理材质预览。
- 调研初期本机未找到 Blender 和现成网格重建命令；本轮实施已配置并完成定向验证，见实施记录。

建议分三步落地，每步都有独立成果：

1. **物体独立保存**：选区快照、名字、来源变换、缩略图、独立 PLY 导出。选区确认不修改原工程，不直接执行裁剪。
2. **表面重建与材质创作**：在代表性物体上评估法线估计和表面重建，先支持扫描充分的静态物体；后台任务可取消，失败保留点云，材质预览复用一次重建结果。
3. **Blender 交付**：首选 GLB，带网格、法线、原色或所选 PBR 材质；旁附原始点云和来源说明。保留原色资产与创作资产的身份，不声称自带 UV 纹理。

选择 GLB 是因为 Blender 官方列出了 glTF/GLB 导入能力，格式也适合承载模型和材质。原生 `.blend` 需要额外的 Blender 转换链及版本验证，首版不默认要求用户安装插件。[Blender 格式支持](https://www.blender.org/features/pipeline/)、[glTF 材质说明](https://docs.blender.org/manual/en/5.1/addons/import_export/scene_gltf2.html)。

重建路线先在样本上评估，不先绑定算法。Open3D 文档说明 Ball Pivoting 使用法线和球半径，Poisson 可能向低密度甚至无样本区域延伸；因此自动补面必须有明确的创作标记与原始数据对照。[Open3D 表面重建说明](https://www.open3d.org/docs/release/tutorial/geometry/surface_reconstruction.html)。

## 验收边界

- 新手能完成选取、剔除背景、旋转检查、命名、导出；框选错误可撤销。
- 切换材质保留形体与原色，操作过程中没有等待重建的假进度。
- 用扫描充分的物体、单面扫描、薄结构和带背景的选区分别验证，不只展示一个漂亮样例。
- Blender 实际导入验证尺寸、朝向、枢轴、颜色、法线和材质；GLB 文件生成成功不能代替这项验收。
- 普通扫描缺少的信息明确保留为未知；没有实测依据时不承诺可打印、工程精度或自动完整重建。
