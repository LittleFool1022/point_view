# 点云与 CAD 联动方案

## 目标与交互

主界面左侧保留唯一的三维点云画布，右侧沿用 CAD 悬浮弹窗。弹窗参数默认折叠，生成图纸、更新和导出始终可见。窄屏保留「三维空间 / 关联图纸」切换，选择状态跨视图保留。关闭图纸后恢复进入前的三维视角。

以「打开自己的空间 → 看清关联 → 生成图纸」组织新手路径。使用「空间轮廓 / 完整图纸」解释 CAD 的模型与布局视图；参数按需展开，避免首次操作先学习专业术语。

质量评价改为「空间检查」：优先显示最多三项可读发现及对应建议，详细指标和检查标准折叠。保留原有报告算法和导出数据，说明报告来自导入文件、不随编辑重算，不能据此证明拼接精度、同步和完整性。

- 悬停：临时高亮关联内容，离开恢复锁定内容，不移动相机。
- 点击：锁定关联内容。默认开启「点击随动」，仅平移另一侧观察中心，保留旋转方向与缩放。
- 定位关联：用户主动适配关联范围。手动拖动中止正在进行的视角过渡；减少动态效果时直接定位。
- 清除：按钮或 Esc 清除联动选择，再次 Esc 才关闭 CAD。标注放置优先消费 Esc。
- 联动选择独立于点云编辑选择，不触发裁剪、隐藏、移动或导出过滤。
- CAD 图层关闭后，不再拾取或保留该图层的联动高亮。

## 映射事实与边界

`projectCadPoint()` 的实际链路为 XY 旋正 → XY/XZ/YZ 投影 → 可选二维旋正，出图再从米转换为毫米；比例只影响排版，不改变模型坐标。

生成图纸时保留运行期源点云、墙带原始索引和实际使用的旋正参数。沿用原始坐标，不逆算一个不存在的唯一深度。

- POINT_CLOUD：采样图元记录 sourcePointIndex，准确回到生成时的三维点。
- OBSERVED_WALL：只从生成时的墙带候选中查找投影邻域，以格网分辨率确定容差，标注为「投影邻域」；不声称这些点是逐实体拟合内点。
- 三维点反查图纸：显示实际投影位置及容差内实测墙线；投影重叠允许多个候选，不强制宣称唯一对应。
- 推断墙、尺寸、轴线、图框和人工标注：允许图纸本地选择，不虚构源点对应。
- 运行期索引不写入 DXF 或成果包；仅采样点的轻量原始索引进入现有 metadata 字段。

## 状态、性能与实现边界

源数据或出图参数改变时暂停联动和导出，保留旧预览供查看，更新预览后重建映射。新预览替换源快照，关闭弹窗释放查询索引与联动选择，保留一份源快照供再次打开核对。

邻域查询使用最多 120,000 个墙带采样点建立二维格网，结果明确为采样候选。邻域查询缓存按图元复用；两侧悬停拾取按 80 ms 节流，不在每次鼠标移动时遍历完整原始点云。点云高亮使用独立覆盖层，不重建全量点云颜色缓冲。CAD 打开期间复用主画布，并将渲染采样上限设为 120,000 点，隐藏相机与地图等辅助面板。

本轮不改变墙体拟合算法，不做双向滚轮/旋转强制同步，不调整手工标注的三维语义，不更新 AppImage。

## 验证与停止条件

获得测试授权后，覆盖三视图、旋正与毫米坐标、精确点索引、投影多义性、推断图元拒绝映射、隐藏与非有限点、源快照失效；再进行前端构建与定向浏览器检查。确认悬停不随动、点击可随动、关闭随动仍高亮、标注/图层/窄屏切换不冲突。
