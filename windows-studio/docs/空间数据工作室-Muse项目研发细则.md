## 1. 可直接提交给 Muse 的项目说明

我要完成“观曜空间数据工作室 Windows 工程交付版”。软件面向建筑测量、既有建筑改造和室内工程，把真实采集点云转为可编辑、可复核的 CAD 图纸及 BIM，并在工程交付能力稳定后提供基于建筑模型约束的 AI 效果图。

请帮我按本文任务 ID 跟踪研发，把每项任务拆为可执行动作，并记录负责人、依赖、下一步、阻碍和验收证据。先推进测量数据质量、墙网与房间闭合、CAD 工程标注，再推进 BIM 自动化和交付兼容性；AI 效果图排在其后。不要把已有代码、候选生成、文件导出或界面可操作直接视为工程精度验收完成。未确定的精度阈值、工期、接收软件和 AI 提供方应作为待决策项保留。

项目阶段目标：同一真实测量工程完成“导入 → 点云清理 → 墙体/房间复核 → CAD/BIM 联动 → 交付检查 → Windows 保存恢复与正常退出”，且遗留不确定项有明确说明。最终工程交付放行需补齐独立测量真值及目标 CAD/BIM 软件验收。

## 2. 产品范围与优先级

1. 第一优先级：可靠的测量成果管理、点云编辑、工程 CAD 和可核验尺寸。
2. 第二优先级：建筑模型编辑、墙/门窗/房间语义、IFC 与 CAD 同修订交付。
3. 第三优先级：有建筑结构约束、可追溯来源的 AI 建筑效果图。

不纳入本项目主线：物体收藏、自由曲面创作、旧物体重建工作台改造、采集设备固件和 SLAM 算法改造。DWG/RVT 原生适配、云端协作和亿级点云支持需单独评估后纳入。

“一键 BIM”指启动可取消、可复核的自动分析流程，不代表缺测部分可以凭空补齐。自动候选、人工修改及实测依据必须区分。参考截图用于确定交互和成果方向，不作为算法精度或竞品技术实现证据。
