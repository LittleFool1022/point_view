# 房间提取改为平面图最小面（零闭合修复 c）

本文记录 `roomsFromWalls` 从“整条连通分量端点度均为 2 才算房间”改为“平面图最小面即房间”的口径、
未闭合问题的输出方式、对下游模型的影响，以及真实样本复跑结果。诊断背景见
[墙网与房间闭合诊断](room-closure-diagnosis.md)（#7 / PR #8）。

## 2. 提取口径

1. **墙网节点**：墙轴端点在 `ROOM_NODE_TOLERANCE_M = 0.02 m` 内合并为同一节点；穿过节点的墙段在该处切成独立边
   （T 形处一段墙变两段），平面图才与真实墙网一致。
2. **最小面**：每条有向半边取“转角最小”的顺时针邻边遍历，得到该连通分量的全部有界面；逆时针（正面积）的
   面即最小面候选。T 形、十形、共享内墙的多房间网络都各自成面，不再要求整条分量端点为 2 度。
3. **简单化**：面环去掉首尾重复点、T 形处沿原轴往返的尖刺与共线中间点——它们不围出面积，保留会让半墙厚
   收缩求交退化。
4. **净边界**：每条墙轴向房间内侧偏移半墙厚，相邻墙轴交点构成净边界；收缩后自交、或面积不减少的面被拒绝。
5. **健全性下限**：`ROOM_MIN_AREA_M2 = 0.5 m²`（命名常量）——小于此值的最小面多为墙厚或交叉产生的窄条，
   不当作房间；被下限淘汰的面数在 `ClosureReport.rejected.smallFace` 中计数。这是几何健全性下限，不是精度阈值。

每个房间输出 `loop`：`wallIds`（组成墙段，可在模型中回查 `Wall`）、`nodesM`（墙网节点）、`areaM2`（墙轴围合面积）、
`perimeterM`（墙轴周长）；`boundaryM` 仍是净边界，`buildingQuantities` 与 CAD 图纸沿用同一房间。

## 3. 未闭合问题

`BuildingModel.unclosedIssues` 记录墙网中度为 1 的悬空端及其最近的可连接墙段，**只记录、不补墙、不改几何**：

| 字段 | 含义 |
| --- | --- |
| `kind` | `wall-gap`（沿同一墙轴的延续/洞口）或 `dangling-end`（两侧墙未对齐） |
| `pointM` / `toM` | 悬空端位置与最近墙段上的对应点 |
| `gapM` | 两者距离 |
| `wallIds` | 涉及墙段 |
| `reason` | 中文原因，含缺口距离 |

参数（命名常量）：`ROOM_UNCLOSED_SEARCH_M = 3 m`（在此半径内找最近墙段，超出则不定位）、
`ROOM_WALL_GAP_M = 1.5 m`（同一墙轴上不超过此距离的算缺口/洞口）、`ROOM_UNCLOSED_MAX_PRINT = 50`
（写入模型的条数上限，超出部分仍计入 `ClosureReport.unclosedIssues` 计数）。这些是位置检索与分类参数，
不是精度阈值，也不影响成房判定：门口造成的 1.2 m 缺口照样不补墙、不成房，只是被如实列出。

同一位置从两端都会被发现，已按“墙段对 + 位置”去重；两端都是悬空端的孤立墙段沿墙轴远端与延长方向查找接续墙段。

进入交付：`validateBuilding` 对未复核的未闭合问题输出 `UNCLOSED`（其他检查项不变），因此未闭合问题不会阻止
模型保存或出图，但会出现在“查看检查项”和复核交付报告里，不再静默丢弃整条连通分量。

## 5. 真实样本复跑

原件 `tri_true_color_20260911_200108_286.pcd`，800,000,584 字节、20,000,000 点，SHA256
`6194be9e2bc4ac14f1116bbc206c56dfbec7ded45b2b07bba497904de669293a`（复跑前后未变，源件只读）。
假设标高 0 m、墙高 3 m、墙厚 0.2 m；全量复跑，解码 1.2 s、墙线拟合 0.8 s。

| 阶段 | 修复前（#8 诊断 / 旧口径） | 本口径 |
| --- | --- | --- |
| 墙候选 | 66 | 66 |
| 墙网节点 / 度分布 | 131，度 1 = 130、度 2 = 1 | 同（节点来自同一组墙段） |
| 连通分量 | 65，最大分量 2 段 | — |
| 拼接口径闭合环（全部端点度 2） | 0 | 0 |
| 最小面（有界面） | — | 2 |
| 被最小面积下限淘汰 | — | 2（均为面积 0 的退化面） |
| **房间** | **0** | **0** |
| 未闭合问题 | 不输出 | 50 条写入（缺口 10、悬空端 40；更远的位置不计入） |

**如实说明**：本步在真实样本上房间数仍为 0，且 0 不是“分量被整条丢弃”造成的——墙网里目前只有 2 个有界面，
两者都是同位置平行重复墙围出的面积 0 退化面（#10 去重合并尚未落地），因此没有可输出的房间。改动带来的实际差别是：
未闭合位置（缺口距离、悬空端、涉及墙段）首次被显式列出并进入模型与检查记录，而不是静默丢弃；夹具侧 T 形与
多房间网络已经能成房。修复前数字取自 #8 诊断，未在本分支重跑旧算法（旧算法已不在源码中）。

复跑输出：`windows-studio/artifacts/room-faces/<样本名>/room-faces.json`（逐级计数、未闭合清单、逐段是否属于房间）
与 `room-faces.svg`（灰=墙轴，绿=房间最小面，红=未闭合位置与指向的最近墙段）。该目录不进版本库。
