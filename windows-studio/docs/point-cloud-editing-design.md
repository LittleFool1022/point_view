## 用户任务与当前断点

任务是沿三维点云连续转动视角、擦除噪点，同时保留建筑依据；减少工具切换，不以换色、图标替换文字或新增大量按钮代替交互改造。用户截图包含 2000 万源点、12 万预览预算、13 次清理和60个墙体图元，工程有未保存修改。截图内工作状态不应因后续部署丢失。

- `src/CloudView.tsx:36`：编辑与 orbit 模式互斥，忙碌时导航也关闭。
- `src/CloudView.tsx:63`：左键只能矩形选区，松手打开工具抽屉，再点删除，打断连续清理。
- `src/domain/cleaning.ts:3`：只有投影矩形和轴向裁切，无自由画笔、套索与表面选择；投影规则覆盖前后裁剪面之间的深度。
- `src/domain/cleaning.ts:19`：每次初始化可见掩码并重放所有清理规则；记录最多100条，不能直接把每个鼠标采样点追加为一条规则。
- `src/App.tsx:209`、`src/pipeline/analysis.worker.ts:36`：全量重放后再回传抽样预览，期间全局 busy；CloudView 的 `[cloud]` effect 重建 WebGL 场景。此路径必须改成适合连续编辑的更新方式。

现有正交相机本身可旋转观察三维数据，不需要为了“3D”强制切成透视。首次导入可用三维斜视；已有工程和连续操作保留用户视点。

## agy 首轮确定的交互主线

处于明确可见的点云编辑状态时，默认橡皮擦。三键鼠标完成全部核心操作，键盘只作效率增强。

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 圆形橡皮擦跟随，命中区域即时标红或淡出预览，松手提交一笔；不再逐笔点确认删除。 |
| 右键拖动 | 随时旋转三维视角，不退出橡皮擦或选区工具。 |
| 中键拖动 | 平移。 |
| 滚轮 | 围绕光标缩放；不被笔刷半径占用。 |
| 笔刷半径滑杆 | 仅用鼠标也能调整；Alt+滚轮或方括号键作为可选增强。 |
| 撤销/重做 | 按整笔恢复；Ctrl+Z/Y 仅在点云编辑上下文作用，不抢走文字输入或CAD标注的撤销。 |
| Esc | 放弃正在拖动、尚未提交的一笔，恢复本笔预览，不增加历史。 |

画笔画到稀疏空隙时不能擅自变为导航，也不能把无可靠表面命中当作允许穿透。操作意图由固定鼠标手势决定。

布局方向由 agy 负责：点云清理时扩大三维主画布，CAD可一键对照，保留出图流程；橡皮擦与选区是主要工具，视角预设收进方位控件。高级范围、显示点大小、恢复全部等按需出现。首轮方案仍塞入了过多常驻参数，当前约414px窄栏下的工具条收敛、上下文属性面板与具体排版待 agy 修订确认，不把未确认部分称为视觉定稿。

## Codex 后端契约与必须修正的技术假设

1. **真实空间选择。** 新增一笔轨迹，冻结相机与视口快照、半径、源件哈希、操作编号和源修订；前后端约定同一坐标系。表面模式由完整数据的拾取/深度依据与作用厚度判定；真实厚度单位为米，不能拿 NDC 深度直接比较。厚度须独立可调，不能把0.25m写成通用墙厚或精度容差。可见选择也不等于绝无误删，必须支持准确恢复。
2. **全量与预览一致。** 当前12万点仅是抽样，画圈或隐藏这些点不构成2000万源点编辑完成。前端可预测性标红，Worker确认后才更新真实影响点数与提交状态；必要时按需提供局部更密细节或全量拾取结果，避免稀疏预览决定错误的深度。
3. **增量引擎。** Worker保留完整点云，建立适合区域查询的索引或视图深度缓存；新增一笔只处理相关点并记录变化掩码/点索引。避免每个指针事件重放全部历史；一笔一条事务，撤销/重做使用差异日志。历史须支持连续画笔工作量，不能沿用100条矩形规则限制或只把上限调大。
4. **编辑与导航解耦。** 本地显示即时反馈，后台按操作序号处理；旋转、平移和缩放持续可用。保留同一渲染器和相机，清理回传更新可见性缓冲，不重建整个三维场景。若切源、取消或失败，按源修订丢弃过期结果并回滚本笔，不能污染新工程。
5. **项目、图纸与保存闭环。** 原PCD只读保留；新编辑记录/掩码紧凑持久化，兼容旧矩形/高度裁切工程，并考虑现有16MiB清单容量。保存、生成图纸和导出使用已确认的同一修订，清理后图纸继续标记待更新；不能把尚未同步的画笔预览当作已保存数据。

以上是实现要求；不承诺未经实测的“零延迟”“数百毫秒”或“绝不误删”。

## 实施顺序与验收

先补完整点云画笔/深度和增量撤销契约；再由 agy 落实鼠标事件、画布工具与反馈；Codex 做集成和真实数据验证。单改按钮和圆圈不算完成。

验收需要覆盖：

- 一次连续操作完成“擦除→旋转→擦除→平移/缩放”，无需点击旋转按钮，无强制工具抽屉。
- 曲线快速拖动无采样间隙；Esc取消本笔；逐笔撤销/重做精确恢复，换角度仍一致。
- 前后两层和近邻墙面夹具验证深度策略；无命中不穿透，工具切换不改变深度范围。
- 2000万点原件核对真实受影响点数与预览映射；连续超过100笔、撤销/重做、保存与重开保持掩码和相机/工程状态一致。
- 清理时不重建渲染器、不因后台任务锁视角；记录实际响应时间、帧率、后台耗时和内存，而非以构建成功代替交互验收。
- 后续 Windows 更新前完整保存用户当前13次清理成果；本轮设计评审没有改动该运行工程。
