# 智能 CAD 工作区优化方案

## 核心目标

减少点云人工擦除，直接生成可编辑 CAD；用户在图纸中完成修正、闭合、标注和导出。界面只显示明确操作与一句结果，不展示调试日志。

## 已落地

- **法向墙证据**：binary PCD 保留量化法向，优先使用有效水平法向与跨高度证据；法向不足回退原算法，不使用曲率硬过滤。原始点云、清理规则和点号不变。
- **建筑轮廓筛选**：默认保留外墙边界及与外墙可靠连接的主轴墙段；偏离主轴超过 5° 或孤立的室内候选进入默认隐藏、默认不导出的家具/复核层，不参与尺寸链，原始证据保留。
- **三视总图整体编辑**：智能出图一次生成俯视、正视、侧视并横向合成同一图框；总图是唯一编辑对象，DXF、SVG 与单页 PDF 直接序列化当前合成模型，不从旧单图重新拼接。
- **树木与立面外轮廓**：XY 墙带校验不再错误阻断正/侧视；立面使用俯视墙线确定的建筑范围排除外部高树，默认仅输出总体外轮廓，保留推断来源与复核警告。
- **点云测距**：两点射线拾取在当前可见的完整源点上执行，返回原件点号与三维米制距离；测线、毫米显示和清理失效语义独立于 CAD 标注。
- **室内外自动清理**：两个默认勾选项在完整源点上生成独立、可撤销的原件点号掩码；结构法向、墙柱与水平面优先保护，墙线一致性校验失败时放弃对应规则，原始文件不变。
- **画布编辑**：选择/移动、直线、多段线、矩形、圆、三点圆弧、实线/虚线、删除、端点连线。打印“图纸”视图和待更新图纸只读。
- **自动小缺口连接**：仅处理不超过 120 mm、互不交叉的一对一缺口，结果为 `inferred/inferred`；其他缺口由用户指定两端，结果为 `manual/confirmed`。
- **统一历史**：绘制、移动、删除、尺寸、连线和标注共用一条撤销/重做时间线，支持 Ctrl+Z/Ctrl+Y。
- **交付合同**：圆和圆弧进入工程、SVG、三视图、标注 JSON 和原生 DXF `CIRCLE`/`ARC`；逐图元线型同步到预览、SVG 和 DXF。移动实测墙后转为辅助墙，保留人工编辑警告。
- **工作区收敛**：左侧编辑工具、顶部视图工具、右栏智能编辑/折叠设置/成果导出，底部一句话反馈。

真实文件 `tri_true_color_20261111_163026_094.pcd` 的诊断输出先由 49 段降至 15 段；0.10.6 建筑轮廓筛选后默认输出 9 段，另外 6 段斜线或孤立室内段进入不导出的复核层。该结果用于确认本次真实文件中的误墙线减少，不作为其他场景漏墙率、全部墙段正确或施工精度结论。

## 下一阶段：少人工干预的结构重建

1. **自动楼层范围**：结合竖直法向、Z 直方图与平面拟合识别地板和天花板；失败时保留人工高度范围回退。
2. **室内区域约束**：根据地板/天花板 XY 支撑生成室内掩码，降低窗外植被和室内包络外候选权重，不改写原始点云。
3. **全局墙线拓扑**：合并连续共线碎片、配对墙面估计厚度、建立墙角和 T 型节点；保留强证据斜墙，门洞和缺测补线继续标为推断。
4. **门窗与尺寸**：只在已接受墙面上识别门窗，再生成房间与尺寸链，避免窗外点进入标注。

每阶段先比较同一真实文件的误墙/漏墙和几何偏差，再进入下一阶段；不以线段数量或图面整齐度单独判断质量。

## 操作边界

- 左键只执行当前工具；选择是默认工具，平移是独立工具。
- 圆使用圆心和半径点；圆弧使用圆心、起点、终点；多段线双击或 Enter 完成，Esc 返回选择。
- 自动连接不宣称识别门洞；大缺口、交叉线和歧义连接留给用户。三视总图内直接编辑任意视图，旧版单视工程重新生成后再交付。
- 人工绘制、移动和自动连接均保留来源，不能升级成直接实测。
- 保存工程保留当前图纸，不持久化撤销栈；重新生成前明确提示将清除人工编辑。

## 关键验证范围

- 真实点云完成一次智能出图，确认法向模式与结果摘要。
- 画布完成一次绘制、移动、撤销/重做和保存，工程中恢复相同图元。
- DXF/工程构建检查，以及圆弧跨 0°、自动小缺口和来源校验的定向回归。
