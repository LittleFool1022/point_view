# 观曜空间数据工作室 · Windows 工程主线

当前开发版本为 **0.10.3**。首批用途为**建筑测绘**，核心是专业点云编辑、现状平立剖、准确 CAD 标注和图纸交付；BIM、AI、效果图与关键帧复核收进可选扩展。历史 0.9.3 设备采集与 Windows 实测记录继续有效于原版本，不自动转为本次改动的验收。

主流程：**完整点云 → 单位/坐标核对 → 框选/高度剖切 → 平立面出图 → 尺寸与文字标注 → CAD 复核成果包**。新尺寸以毫米定义点保存，导出原生 DXF DIMENSION、样式及匿名显示块；水平、垂直和对齐标注可捕捉图元端点、删除、撤销和重做。显示取整不改变几何，也不代表测量精度。几何参数变化后的旧图可随工程保存恢复，保持待更新并禁止导出；仅改图幅、比例或取整时保留几何和人工尺寸，不重新拟合。重生成清除人工尺寸前明确提示。

点云的屏幕清理与高度范围均在完整源点上重放；原文件保持不变。CAD 包不要求先建立 BIM，包含来源 SHA256、尺寸定义、标注、清理规则和待核验事项。0.10.1 增加毫米图幅、锁定比例的 DXF 纸空间、矢量SVG/打印HTML和桌面PDF；超框/标题栏重叠时先调整图幅，PDF页面校正不缩放图元或字体。独立实测及目标 CAD 工具验收仍未完成，当前包标为复核用途。当前合同见[架构文档](docs/architecture.md#2026-10-29-当前产品合同点云编辑与专业-cad)。

完整产品链：**OMNI 手持扫描 → 保存完整点云 → 导入本软件离线处理 → 工程成果二次交付**。设备控制与实时预览由 OMNI Scan 承担。技术栈、文件接口、容量断点与分期验收见[端到端架构](docs/architecture.md#13-omni-手持扫描到二次交付的端到端技术栈)。

本目录是新应用入口，产品代码不包含旧“创作 / 物体收藏 / 自由曲面生成”流程。已有 Windows Point View 测试版仍保持原状。产品整体架构、范围和实施顺序见 [架构与产品定位](docs/architecture.md)。

后端剩余功能及验证缺口持续记录在 [建筑测绘后端待闭环清单](docs/backend-open-items.md)。0.10.3 由本机 agy 负责界面与交互，Codex 负责集成验证和 Windows 部署；版本状态以本次发布记录为准。

0.2.0 已实现 Windows 大文件路径：单源件容量上限 2 GiB，binary PCD 完整解码保护上限 5000 万点，实际基准为用户指定的 **2000 万点 / 763 MiB 原件**。完整点集留在 Worker，界面仅接收最多 12 万点预览；大场景 CAD 采用所有源点参与的网格矩聚合，再在聚合结果上拟合。分析方式与源哈希随成果交付，不把显示预算或聚合质心数当成原始点数。

其他格式的大文件解码尚未扩展，仍限制在 256 MiB 兼容路径；大工程的流式保存与恢复请使用 Windows 桌面版。它不是无限规模或已通过建筑精度验收的引擎。

**已发现的精度边界**：8×6 米合成房间，经旧格网墙带算法生成的墙体范围为 8000×6139.535 mm，纵向偏差约 +139.535 mm（当次格网分辨率 186.047 mm）。当前图纸用于复核流程验证，尚未通过工程尺寸验收。诊断数据见 `artifacts/baseline-measurement.json`；架构要求后续采用墙平面/轴线与房间拓扑引擎解决，不能把当前出图闭环当作可施工成果。

## 走通当前工程流程

1. 打开本地应用或浏览器，选择坐标单位后导入点云；也可“打开示例”加载明确标识的合成房间。
2. “生成工程图”，并排核对原始点云和墙带图元。
3. 选平/立面、图幅与比例；修改参数后必须更新图纸才能导出。
4. 复杂整场景可明确选择“投影证据轮廓 · 复核用”；该轮廓可能含非建筑物，不代表墙体识别。填写标注并点击图纸放置；标签可拖动，选中后可删除。门窗标签只做人工说明。
5. 导出 DXF 成果包；保存 `.pvplan` 后可在另一台机器恢复源点云与标注。
6. 在建筑模型工作区生成候选、编辑宿主门窗与房间，再派生模型平面图、导出复核IFC或进入建筑效果图；具体边界见后续0.4—0.6章节。

### 独立尺寸核验版 0.6.1

建筑模型 → 导出精度基准模板 → 填写独立测量信息/参考值/容差/不确定度 → 导入实测精度基准 → 导出尺寸核验报告。可删除未测量项；所有保留项须完整填写。模板不会预填模型尺寸冒充真值。支持墙长/厚/高、门窗宽高/沿墙偏移/底部标高、房间面积/高度、楼层标高；`m` 与 `m²` 按指标分别记录。

每项采用 `abs(model-reference)+uncertainty <= tolerance`，仅报告所列样本是否超差。合成基准与独立实测分开标识，报告固定保留 `constructionAccepted: false`：单项/局部尺寸核验不能替代全工程位置、配准、施工和接收工具验收。模型修订或测量关联变化后原报告失效；核验不改写模型尺寸或人工复核标志。基准与报告单独导出，当前不随工程自动保存。

参考JSON与限制见 [架构](docs/architecture.md) 和 [本轮验收记录](artifacts/installer-qa-20261022/安装升级与尺寸核验记录.txt)。AI提供方、上传范围/预算及真实独立尺寸/阈值仍需用户明确；本轮未选择或调用外部生成服务。
